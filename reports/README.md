# レポート索引

このディレクトリには、`bin/sweep.sh`・`bin/score.sh`で集めた実測値をもとに作成した
最終レポート（HTML）を置きます。使い方のドキュメントは`docs/`を参照してください。

## 命名規則

```
YYYY-MM-DD-<内容のスラグ>.html
```

日付を先頭にすることで、ファイル名だけで時系列に並びます。ローカルLLMは頻繁に
更新されるため、「いつ測ったか」は結果の有効性（まだそのモデルバージョンで
再現するか）を判断する材料になります。スラグは英小文字・数字・ハイフンのみです
（`bin/new-report.sh`が生成時に強制します）。

新しいレポートを作るときは`bin/new-report.sh <スラグ>`を使ってください。
雛形（`_template.html`）から日付入りのファイルが自動生成されます。
