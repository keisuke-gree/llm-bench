# ベンチマークタスク（Claude Code にそのまま貼り付けて使用）

各タスクを実施する前に、必ず `/clear` で会話をリセットしてください。
3つのタスクは独立しています。1タスクずつ、新しいセッションで実施してください。

---

## タスク1

```
このリポジトリで、Bench\Logic\RewardCalculator クラスの applyBonusRate() メソッドを
呼び出しているすべての箇所を特定してください。

調査対象は「RewardCalculator クラスの applyBonusRate() メソッド」の呼び出しのみです。
同名のメソッドが別のクラスに存在する場合は、それを呼び出している箇所を含めないよう
注意してください。

回答は、呼び出しが存在するファイルのパス一覧を箇条書きで示してください。
1つのファイルに複数箇所の呼び出しがある場合はその旨も明記してください。
```

---

## タスク2

以下の型変更を行うと仮定してください（**実際にコードを変更する必要はありません**）。

```
Bench\Model\UserContext クラスのプロパティ $campaignId の型を
「?int（null許容のint）」から「string（null非許容の文字列）」に変更したと仮定します。

このリポジトリ全体を調査し、この型変更によって型エラーになる（または明らかに
不正な挙動になる）ファイルをすべて特定してください。単に $campaignId という
プロパティ名を参照しているだけでは影響を受けない場合もあるため、実際にどのような
使われ方をしているかを1つずつ確認してください。

回答は、影響を受けるファイルのパス一覧を箇条書きで示し、各ファイルについて
「どのコードが、なぜ型エラーになるのか」を1〜2行で説明してください。
```

---

## タスク3

```
以下のテストが失敗しています。原因を特定してください。

対象テスト: tests/Logic/QuestClearLogicTest.php の
testBonusAppliedOnCampaignLastDay()

失敗出力:

1) Bench\Tests\Logic\QuestClearLogicTest::testBonusAppliedOnCampaignLastDay
Failed asserting that 100 matches expected 150.

tests/Logic/QuestClearLogicTest.php:78

このテストやテスト対象のコードを実行する必要はありません（実行環境は用意されて
いません）。コードを読んで呼び出し関係を追い、根本原因を特定してください。

回答は以下の形式で示してください。
1. 根本原因があるファイルパスと行、メソッド名
2. 何が誤っているか（具体的な条件式やロジックを引用すること）
3. テスト対象のコードが、そのテストケースに対して呼ばれるまでの呼び出し連鎖
   （どのメソッドがどのメソッドを呼んでいるか）
```
